# docs/

Documentación viva del monorepo `teremoqwow`.

## Índice

- [architecture.md](architecture.md) — vista de módulos, boundaries y responsabilidades por agente.
- [contracts.md](contracts.md) — índice de esquemas JSON, versionado y ciclo de deprecación.
- [roadmap.md](roadmap.md) — fases 0–3 y mapeo issues ↔ entregables.
- [adr/](adr/) — Architecture Decision Records (formato MADR).

## Convenciones

- Todo cambio arquitectónico relevante requiere un ADR en `docs/adr/`.
- Los diagramas se escriben en Mermaid dentro del propio Markdown; no se versionan imágenes exportadas.
- Los enlaces internos usan rutas relativas al workspace.

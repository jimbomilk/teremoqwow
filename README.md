# teremoqwow

Plataforma de broadcast de latencia ultra baja sobre Media over QUIC (MoQ), con telemetría e interactividad sincronizadas.

## Módulos

- Ingesta SRT (MediaMTX)
- Transcodificación multicalidad (moq-mux + FFmpeg)
- Relay MoQ (moq-rs)
- Orquestación API (KrakenD)
- Sincronización y telemetría
- Player y overlays HTML5
- DRM y monetización
- Federación de nodos
